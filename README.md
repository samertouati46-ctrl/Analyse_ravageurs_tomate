# Analyse de l'effet des traitements phytosanitaires sur l'infestation de tomate

## Objectif

Évaluer l'effet de différents traitements sur l'abondance d'un ravageur de la tomate.

## Organisme étudié

Culture : tomate

Ravageur : Bemisia tabaci

## Données

Les données comprennent :

- Parcelles expérimentales
- Types de traitements
- Nombre d'insectes observés
- Hauteur des plantes
- Rendement

## Méthodes

Analyse réalisée avec :

- Python
- Pandas
- NumPy
- Seaborn
- Google Colab

## Reproductibilité

Le notebook contient :

- les données
- le code d'analyse
- les graphiques
- l'interprétation scientifique
